# Terraform and Azure – Learning Summary

## Overview

Today, I studied the fundamentals of **Infrastructure as Code (IaC)** and Terraform, focusing on how Terraform can be used to provision and manage Azure infrastructure efficiently and consistently.

## Topics Covered

### 1. Infrastructure as Code (IaC)
- Understood the concept of IaC and why it is important.
- Learned the limitations and challenges of traditional manual infrastructure provisioning.
- Explored the benefits of automating infrastructure management.

### 2. Terraform Fundamentals
- Learned what Terraform is and its key benefits.
- Understood the Terraform workflow and installation process.
- Explored Terraform providers and how they interact with cloud platforms.

### 3. Terraform Providers and Versioning
- Learned about Terraform providers and their role in managing Azure resources.
- Understood the difference between Terraform Core and provider versions.
- Explored version constraints, version operators, and the importance of version compatibility.

### 4. Azure Resource Management
- Learned about authentication and authorization for Azure resources.
- Practiced creating and managing Azure Resource Groups.
- Explored Azure Storage Account management using Terraform.

### 5. Terraform State Management
- Learned how Terraform tracks infrastructure using the state file.
- Understood how Terraform identifies infrastructure changes and updates resources.
- Explored state file best practices and remote backend configuration.
- Studied the importance of remote state management for collaboration and consistency.
